## Descripción

Este proyecto consiste en el desarrollo de una novela visual interactiva en Unity. El objetivo fue crear la estructura base de una novela visual, 
implementando un sistema de diálogos, navegación entre pantallas y diferentes interfaces de usuario para controlar la experiencia del jugador.
La aplicación permite al usuario recorrer una historia mediante diálogos secuenciales e interactuar con diversos menús para configurar opciones,
pausar la experiencia o consultar los créditos del proyecto.

## Funcionalidades Implementadas

### 💬 Sistema de Diálogos

* Presentación secuencial de diálogos.
* Navegación entre líneas de texto.
* Sistema de avance mediante interacción del usuario.

### 🏠 Menú Principal

* Inicio de la novela visual.
* Acceso al panel de configuración.
* Acceso a créditos.
* Opción para salir de la aplicación.

### ⚙️ Panel de Configuración (Settings)

* Interfaz dedicada para futuras configuraciones del juego.
* Navegación de regreso al menú principal.

### ⏸️ Menú de Pausa

* Interrupción temporal de la novela visual.
* Reanudación de la historia.
* Acceso a otras opciones del sistema.

### 🎬 Créditos

* Visualización de información sobre los desarrolladores y el proyecto.
* Navegación de regreso al menú principal.

## Tecnologías Utilizadas
